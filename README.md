# Portable ScreenShot

## 用法

1. 运行 `PortableScreenshot_v1.0.exe`。首次运行会在 exe 同目录生成 `config.json` 和 `Screenshots\`。
2. 设置窗口 → **快捷键** → 截图键 → 点 **绑定…**
   - 弹窗里依次按下要绑的键，**按 Esc 确认**（立刻生效并写入配置，不需要再点保存）
   - 一个键都没按就按 Esc = **取消绑定**，此后没有任何键能触发截图
   - **Backspace** 回退一个键；点 ✕ 关闭 = 保持原绑定
3. 组合键**顺序敏感**：绑成 `Z → Ctrl` 就必须先按 Z 再按 Ctrl，反序不触发。两键间隔超过 1 秒算两次独立按键。
4. 点 **隐藏到后台** 收进系统托盘，截图键继续有效。托盘图标：双击 = 打开设置，右键 = 打开设置 / 退出。
5. 图片存进"保存目录"，例如 `shot_20261007_141005_537.png`。

同一时间只允许一个实例；重复双击只会唤起已经运行那个实例的设置窗口。

## 设置项

| 分区 | 项 | 说明 |
| --- | --- | --- |
| 输出 | 图片格式 | `png` / `jpg` / `bmp` |
| 输出 | JPG 质量 | 50–100，滑杆旁边会写明当前档位的效果与代价；非 jpg 时该项禁用 |
| 输出 | 命名方式 | `timestamp`（时间戳）/ `sequence`（`0001` 递增） |
| 输出 | 文件名前缀 | 最长 32 字符，`\ / : * ? " < > \|` 会被过滤掉，防止把文件写到保存目录外面 |
| 保存位置 | 保存目录 | 可浏览选择；**在资源管理器中打开** 直接跳到当前目录 |
| 抓取范围 | 显示器 | 主显示器 / 全部显示器拼成一张 / 单个显示器 |
| 附加选项 | 同时复制到剪贴板 | 以 CF_DIB 写入，可直接往微信、画图、Word 里粘 |
| 附加选项 | 截图提示音 | 不播放 / 系统音效 / 自定义文件（挑一个 `.wav`，选完立刻响一声给你听）；行尾**试听**按钮按当前选择放一遍 |

只有 `png_compression`（0–9，默认 3）没进界面，需要的话直接改 `config.json`。

提示音选"系统音效"时用的是 `%WINDIR%\Media\Windows Notify.wav`；那个文件被删掉或改名的话就不出声，不会报错。

## 从源码构建

双击 `build.bat`，三步：装依赖 → 跑 16 项自测（会真的抓屏，让桌面保持可见）→ PyInstaller 打成单文件 exe。

- 产物：`dist\PortableScreenshot.exe`（约 28 MB）
- 自测输出会同时存到 `build\selftest.log`，窗口跑完停住等按键，不会一闪而过
- exe 不入 git；要分发请挂到 GitHub Release
- 开发环境：Windows + Python 3.10，依赖 `mss` / `Pillow` / `pystray` / `pyinstaller`

## 命令行参数

| 参数 | 作用 |
| --- | --- |
| `--selftest` | 跑 16 项自测并退出，退出码非 0 表示有失败项 |
| `--no-gui` | 不弹设置窗口，只挂截图键（配合 `config.json` 用） |
| `--no-tray` | 不创建托盘图标 |

## 实现要点

- 按键监听用 `WH_KEYBOARD_LL` 低级键盘钩子，不是 `RegisterHotKey`，所以任意单键都能绑、键序列可以做成顺序敏感。钩子回调只往队列里丢一个信号，匹配与截图在工作线程上做——钩子回调卡住会拖慢整台机器的输入。
- 抓屏用常驻的 `mss` 实例，抓到像素就立刻返回，编码和写盘交给后台线程；先写 `.part` 临时名再 `os.replace` 原子改名，中途被杀不会留下半张图。
- 实测 2880×1920：单张抓屏 80–120 ms；连打 5 张全部落盘，单张抓屏 83–95 ms。
- 配置文件按不可信输入处理：前缀会清洗，保存目录指向文件时不会直接 `startfile`。

## 已知限制

- **以管理员权限运行的程序会屏蔽低级键盘钩子**（UIPI）。要在那类窗口下截图，请用管理员身份运行本 exe。
- **独占全屏（exclusive fullscreen）游戏可能拍到黑屏**，改用"无边框窗口"模式即可。
- exe 未签名：首次运行可能遇到 SmartScreen 提示；全局键盘钩子也可能被部分杀软报出来，加白名单即可。
- Windows 11 默认把 PrtSc 交给"截图工具"。绑 PrtSc 时建议先在系统设置里关掉那个快捷键，或者干脆绑一个系统不占用的键。
